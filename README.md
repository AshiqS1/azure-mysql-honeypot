# MySQL Database Destruction & Ransom Extortion - Microsoft Azure, Sentinel, Defender XDR

Project Description: 
- Built a honeypot database server with an open firewall and exposed it to the public internet for 4 days.   
- 2 threat actors brute-forced it in 4 hours, exfiltrated data, and left a ransom note demanding 0.0135 BTC.
- Wrote 2 custom analytics rules in Sentinel (KQL) to detect initial access across 34 alerts and 2 incidents.
- Full incident report on GitHub ([https://github.com/ashiqs1/azure-mysql-honeypot](https://github.com/ashiqs1/azure-mysql-honeypot)).
